# Contributing

Inkbook is not accepting unsolicited code contributions during private development. Issue reports may be enabled for invited collaborators. Do not submit code derived from the adjacent reference project or any source whose license is incompatible with Inkbook.

Authorized work must follow `AGENTS.md`, the clean-room provenance contract, Conventional Commits, and all repository quality gates. Every technical artifact uses English. Security reports follow `SECURITY.md` and never use public issues.
