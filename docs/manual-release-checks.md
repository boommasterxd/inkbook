# Manual Release Checks

This checklist supplements the [quality and release acceptance contract](quality-and-testing.md#release-gate).

Manual checks are not smoke or end-to-end test suites. They are focused acceptance measurements for behavior that cannot be represented faithfully in the automated harness:

- pen latency and palm rejection on one supported stylus device; on affected Linux pen hardware, record the Obsidian/Electron version and Wayland or X11/XWayland backend and verify native crosshair selection separately from SVG icon and ring feedback. CSS cursor selection may not control a separately managed tablet-tool cursor. Xvfb and synthetic pen events do not establish physical S Pen behavior
- touch arbitration and pinch on iOS and Android
- mouse, trackpad, keyboard, and focus behavior on desktop
- inline formulas in headings at representative heading scales, effective bold and explicit Bold-off, and normal text; narrow operator chains retain their glyph size and full content across multiple lines, fractions and roots do not overlap following text, and editor/SVG/native PDF agree; verify indivisible matrix fitting separately
- Markdown pipe tables in text fields across desktop, tablet, and phone in both themes: verify the [table editing contract](text-fields.md#source-formatting-and-mathematics) by pointer, touch, and keyboard, including focus, inline formatting and math source reveal, navigation, temporary row growth, append and menu actions, and the full-source return; exercise newly typed and pasted tables, literal pipes and multiline clipboard input; verify Undo/Redo, save and reload, visible-row windowing and retained scroll extent, and matching static SVG and native Obsidian PDF with following content and embedded fonts
- guided font import from the font picker in desktop, tablet, and phone modes in both themes, using keyboard as well as pointer/touch: choose one or multiple valid files and confirm that selection, validation, preview, and review create no vault files before final confirmation; verify detected editable family names, recognized face variants, the single native-font preview, optional explicit assignment to an existing family, and successful batch commit; exercise Back and cancellation, invalid files, duplicate content, family conflicts, capacity errors, and retry recovery; confirm focus returns to the picker and existing document font bindings remain unchanged
- delayed Copy, Cut, and Paste on supported desktop, iOS, and Android WebViews, covering the successful prefixed `text/plain` system representation, synchronous `ClipboardItem` construction failure, rejected system write, custom-format read compatibility, in-session fallback, and no Cut removal after an intervening edit, selection change, or detachment
- right-hand native Obsidian scrollbar behavior before, during, and after pen drawing in Reading view, Live Preview, and a pop-out: persistent desktop track where the operating system exposes one, unchanged gutter and `clientWidth` everywhere, no overlay by Inkbook UI, and recorded OS-controlled auto-hide behavior on native overlay-scrollbar systems
- mouse, touch, and keyboard canvas context menus with the specified icons, disabled Arrange boundaries, and red text plus icon for destructive entries
- active-scene, Reading-view, Live Preview, and saved-SVG graphic parity in light and dark schemes, including a pop-out window and one external vector editor; software without media-query support must show the deterministic light fallback
- host-theme chrome, high contrast, and reduced motion
- hold-to-shape with visibly irregular self-generated pointer examples on the native canvas: straight and curved lines, asymmetric heads at both arrow endpoints, near-boundary closed-head attachment in both stroke orders, all closed shapes including star, negative scribbles and failed positive attempts, transparent preview behind original ink, early release, jitter, continue-and-hold-again, one-step history, native connection snapping with target movement and disabled-snapping counterexamples, settings reset and persistence, and cancellation; freeze a separate evaluation subset before tuning and distinguish virtual-display/CPU-throttled evidence from physical-device latency
- first appearance after insertion and note opening in Live Preview and Reading view, including pointer-through loading indicators and partial-preview remount continuity, frames before placeholder mounting, late source-path assignment without document changes, zero-to-48-pixel placeholder growth and early replacement from its current height, shared spinner timing and uninterrupted automatic-activation handoff, later manual activation with a fresh delay, placeholder/intermediate/final heights, cached zero-height appearance, failed recognition restoration, sequential autoactivation, reduced motion, width retargeting, occurrence retention across remounts, and disposal before readiness
- bounded recognition admission, completion-time cache eviction, faulty subscribers, cancellation, long-note insertion validation, and maximum-capacity Live Preview prose edits and coalesced recognition bursts
- 10,000-stroke frame, memory, unlock, animation, and export budgets
- native Obsidian Markdown-to-PDF export on A4, A5, and landscape layouts, compared against the same locked editor document at the same rendered width and target document color scheme; cover four background families, a short embed that fits the remaining current page and must stay there, an embed that does not fit the current page but does fit a full page and moves whole only when current remaining room is at most 16%, a high embed that otherwise starts on the current page and splits, a long/10,000-stroke embed that must flow across pages, and a large element crossing candidate cuts. Verify real print-fragment placement, no-crossing then minimum-interval cut preference, the 64-pixel/two-radius/border/24-pixel minimum-room rule, the preferred bounded lookback and at most one earlier crossing-free fallback within the current piece, 12-pixel continuation gap, rounded frame padding, source-coordinate continuity, and complete bottom-stroke visibility. Exercise invalid geometry, unavailable print fragments, and the 256-piece cap to confirm fallback keeps the complete graphic. Verify page and ink colors, guides, shell pseudo-element background, border, shadow, responsive corner radius, transparent one-pixel preview inset, media aspect ratio, and bottom edge follow the PDF render target rather than the source editor. If a dark editor produces a light PDF target, the export graphic must be light; use a dark target document to verify dark output only when the target actually resolves to dark, without assuming native Obsidian offers a dark PDF mode. Capture matched renders, measure and report raster differences honestly, and claim exact parity only when zero difference has been measured; geometry or guide-path presence alone is not proof. Export the same note natively at 100%, 75%, and 50% downscale with identical paper, margins, and target theme. Measure effective text size and representative frame/ink dimensions in the PDFs, verify proportional scaling, intact small forms across page boundaries, and restoration after print. Cover fresh options, canceled native dialogs followed by another renderer, source changes, concurrent source windows, malformed or unavailable native options, and complete-graphic fallback without cut geometry. Confirm no export UI controls, unchanged host ownership of native image embeds and ordinary links, unload restoration, and fail-closed ambiguous escaped-literal correlation. Exercise Reading-view vault-source correlation plus unsaved edits in active Live Preview and Source mode, confirming the expected source buffer is used without modifying it. Include touching element endpoints with no empty clear span and near-tangent endpoints separated by one rendered CSS pixel to verify the cut-clearance rule. Treat other MarkdownRenderer consumers as supported only when their sectionless output and source are available; raw Markdown/Pandoc behavior is not a universal acceptance target. See [Native PDF Export Pagination](export-pagination.md) for the canonical behavior.
- native PDF text alternatives: verify normalized author descriptions and the default label survive PDF text extraction once per occurrence, in note order, including repeated drawings with different labels, long or multilingual descriptions, short first fragments, both target schemes, and transparent legacy graphics. Compare visible output against the same export without the text alternative. Exercise nearly full-page drawings with small current-page remainder and following prose; if native page allocation cannot accommodate the plan, confirm complete-graphic fallback retains every note paragraph rather than dropping trailing content.
- in-place lock and unlock with identical root, width, attachment, and top-edge anchor; the same block animates once between exact locked and active heights without duplicate insertion, stale preview border, flicker, unintended scroll jumps, or editor remounting; unlock hides the preview and exposes the complete active scene, foreground, toolbar, and input in the first growth frame while retaining the hidden preview until cleanup; coverage includes active-at-native-bottom lock, retained-range editor disposal, direct unlock without intervening scroll, and deliberate-scroll reserve release
- unlock, committed content growth, window resize, zoom layout, and eraser-driven shrink at several intermediate frames, including a top-row-only document, fractional CSS-pixel rounding, and one-step growth larger than two initial viewports, proving that the prepared envelope is aligned to writing rows, never shorter than the visible canvas, stays top-anchored, waits for a complete renderer frame before growth, progressively reveals the already complete pattern, performs zero background builds during clipping, and leaves exact final height and scroll compensation after interruption
- every background type and S/M/L/XL spacing, including rapid S/XL/M/S preview retargeting, proving that active height, current container block size, camera, and native scroll position remain unchanged while pattern geometry updates atomically, and that commit updates the next locked target
- successful eraser removal keeps every affected path at its final fade state until the same scene barrier detaches it, creates no exit tombstone, and never restores stale opacity or geometry before an automatic shrink begins
- empty locked previews with at least 2.5 writing lines rounded to the next writing row, no clipping by host button sizing, and the same minimum after reload
- active and standalone SVG verification across every absolute S/M/L/XL spacing that the fixed inner frame never moves, squares retain all four outer boundaries, dots occupy the exact corresponding square intersections, lines retain only horizontal guides, the 100 / 3 spacing closes each canonical 100-unit row without a floating-point terminal sliver, a non-divisible final interval closes exactly at the right or bottom frame edge, both renderers share the same canonical axes and 25-percent-alpha palette, the active scene uses one bounded full-page pattern coverage path plus at most one terminal path, input remains available throughout the margins, and content entering the bottom margin restores a complete margin after growth
- attached save recovery restores the active page height and camera before presenting its compact icon-action overlay at the shared window-level feedback position, so all four writable SVG margins remain visible and no failed-lock measurement reads a released document page
- attached load and save recovery, retryable activation, insertion Undo, clipboard, history, copied-embed Paste, and embed action feedback use the shared status-icon surface with concise outcome-aware copy; presentation and non-presentation feedback share the owning window's upper-right desktop/tablet or upper-center phone overlay defined in [Embed UI](embed-ui.md), remain stable across scrolling, zoom, and resize, and avoid overlap between independent anchors; pop-out ownership and lifecycle cleanup are preserved, and identical-anchor messages replace instead of stack, and no retry, keep-preview, dismiss, undo, copy, reload, delete, or continue action substitutes a text button
- editor-interface startup failure produces one attached recovery surface without an additional native Obsidian notice, while failed or stale copied-embed Paste, clipboard read or encoding, rejected standard system clipboard writes, and failed Canvas history traversal produce the matching typed feedback without changing recoverable data; a rejected system write retains the validated in-session payload
- loading and saving feedback under intentionally blocked worker and vault operations, including the 500-millisecond recognition/automatic-loading boundary, the delayed manual-opening overlay and minimum visual lifetime from [Embed UI](embed-ui.md#loading-feedback), no intermediate border, dimming, or blur on fast opening, no repeated hold after a long load, the next-animation-frame pending-state recheck, completion between threshold and paint without a mounted loading flash, the 150-millisecond save boundary, an unknown unlock target height, immediate semantic loading cleanup at scene handoff, live changes to the presentation's motion preference before and after spinner mounting, exact-revision successor saves, Retry, immediate failure recovery without a visual hold, reduced motion, and cleanup on detach or plugin unload
- toolbar spacing and native-sticky behavior proving that opening reserves space above the paper, closing collapses it, preceding Markdown remains unobscured, interruption and reduced motion settle correctly, scroll-owner top padding is compensated without private selectors, the toolbar pins at the [usable top edge](embed-ui.md#toolbar-design), and the embed bottom bounds its sticky lifetime; in phone Reading view and Live Preview, actual touch taps on pinned Select and Eraser must change the tool with the native header hidden, in both themes, and keyboard focus must remain unobscured
- confirmed persistence propagates the current locked aspect ratio to every mounted preview before resource refresh, so a non-empty patterned lock shrinks to the complete occupied pattern row plus exactly one pattern row, a background-free lock retains one trailing 100-unit writing row, and unlock grows back to the background-independent `activeHeight`
- strict canonical parsing and persisted-output verification reject changed fixed-frame background geometry; unlock accepts safe static variations without rebuilding contours, rejects forbidden markup and invalid metadata, and renders only validated snapshot geometry
- owned toolbar Overflow opening directly below its three-dot trigger; selected toolbar foreground transitions and immediate pressed semantics; owned Background panel handoff and Back-to-Overflow actions through mouse, touch, keyboard, and native host-history Back and public keymap Escape dismissal; Settings and Keyboard-shortcuts actions, including retained phone sheet/host/backdrop identity, animated subpage height growth and shrink, rapid navigation interruption, and Back-to-Overflow before final dismissal; responsive shortcut recording, clearing, reset, Inkbook and effective Obsidian conflict feedback, and tab navigation; height-invariant live background-spacing preview, one final history and save commit, and atomic rollback after a rejected commit; owned Shape and Style surfaces, with selected Style choice background, border, and foreground transitions while checked semantics update immediately; all 25 Arrow endpoint combinations; distinct 2D and 3D coordinate-system icons; rounded Style controls with 44-pixel touch targets, subject only to the [existing phone Style opacity-control exception](quality-and-testing.md#accessibility-acceptance); exact primary-toolbar centering while context buttons appear; Canvas context-menu section separators with an icon on every actionable entry; straight-highlighter centerline handles, 90-degree line and arrow snapping, 45-degree coordinate-axis snapping, endpoint-to-endpoint connections, and table separator handles across desktop, tablet, and phone modes
- consecutive stroke commits, autosaves, resource refreshes, and theme changes without active-editor detachment, widget remount, focus loss, or session closure
- Reading view, Live Preview, Source mode, pop-out windows, settings search, enable, disable, and reload without leaked listeners, workers, scrollbar leases, host-element references, menu sessions, or React roots
- production editor-chrome module loading under Obsidian's default CSP in the main window and a real pop-out realm, including distinct owner-document React roots, toolbar measurement before input handoff, close-before-load cancellation, retryable CSP/import failure, timeout cleanup, and no retained Blob URL
- rapid activation across tabs and pop-outs, closing a dirty tab or pop-out before autosave, detached save success and failure recovery, and two independent Obsidian instances editing the same file

Each release records pass/fail evidence and any accepted limitation.
