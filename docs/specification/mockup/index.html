Vector spaces

A vector space combines vectors with two operations: vector addition and scalar multiplication.

Linear independence

A set of vectors is linearly independent when only the trivial linear combination equals zero.

Geometric intuition: no vector in the set can be assembled from the others.

Basis and dimension

A basis is a linearly independent spanning set. Every vector has a unique coordinate representation in that basis. 

span(v₁, v₂) = { a·v₁ + b·v₂ | a,b ∈ ℝ }
